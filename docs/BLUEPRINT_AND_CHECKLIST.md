# Aether — Blueprint & Living Checklist

**Version:** 1.1 (handoff)  
**Date:** 17 October 2026  
**Status:** Source of Truth  

## Vision

Aether is a personal and business AI teammate on iPhone and iPad.  
It listens without interrupting, remembers across voice and text, grows via plugins, answers with Smart UI, and progresses toward real device control.

## Six Core Pillars

1. Unified Memory
2. Push-to-Talk / Voice-Lock
3. Plugin System
4. Device Computer-Use
5. Smart UI
6. Persistent Identity (later)
